寶藏獵人與六階護符

收集碎片、合成藏寶圖、追蹤線索；高階尋寶需要擊敗專屬守衛。累積成功紀錄後，再到奇岩製作護符。

碎片合成普通尋寶高階守護戰地點查詢碎片來源護符配方能力卡關排查

從碎片開始，不必先找製作 NPC

普通怪物掉落的「藏寶圖碎片」是普通尋寶的起點。把同品質碎片收齊放在背包，使用碎片即可合成對應藏寶圖。先別把所有碎片合光，後面升級護符也會用到。

普通尋寶：跟著訊息走

  1. 使用普通藏寶圖

    系統隨機指派一個目標，訊息會顯示地區、地圖與座標。不是自行從下表任選一點。

  2. 前往正確地圖

    座標相同但地圖不同也不算。先確認地區，再走到目標 X、Y 附近。

  3. 3 格內再使用

    到達目標 3 格內使用同一種地圖，確認系統顯示尋寶成功與獎勵。普通階段不必打守衛。

  4. 保留材料與紀錄

    成功會消耗 1 張普通藏寶圖並累積普通與總尋寶次數。繼續收集碎片，準備護符升級。

普通完成可取得金幣 500～1,500，以及經驗藥水150%(綁)、藏寶圖碎片、魔物殘魂或英雄秘笈碎片其中一類額外獎勵；另有機會發現精良藏寶圖碎片。數量請看成功訊息。

精良以上：地圖先留著，擊殺後才消耗

精良、稀有、傳說的第一次使用會指派目標；到達同地圖的目標 3 格內再使用，才召喚守衛。必須由目前尋寶角色完成對應守衛的擊殺判定，才會扣地圖、記錄次數並發放獎勵。

  1. 先完成目前尋寶

    同時只進行一個階段，不要在普通尋寶還沒完成時切換高階地圖。

  2. 到位置再召喚

    帶好地圖與補給，到指定目標 3 格內再點一次。

  3. 擊殺自己的守衛

    守衛已出現時不要重複召喚，也不要把地圖移出背包。

  4. 確認成功訊息

    成功才消耗地圖。確認獎勵與完成次數，再開始下一張。

尋寶卡住，先確認這些

碎片夠了卻合不出地圖？

確認是同一品質碎片：普通10、精良15、稀有15、傳說20。先預留背包空間，使用碎片，不是拿去護符升級師合成地圖。

一直叫我到3格內？

確認地圖編號和 X、Y 都正確，走近指定位置。到另一個候選地點或同座標的其他地圖都不算。

提示已有其他尋寶任務？

先完成目前那一張，不要在不同品質之間反覆切換。進度不會因為多點幾張就變成同時接多個。

打倒守衛卻沒完成？

確認是這次召喚的守衛、由尋寶角色完成擊殺判定，而且對應藏寶圖仍在身上。以系統成功訊息判斷，不以看到守衛死亡就認定完成。

護符拿到後目前血量沒有補滿？

護符增加的是最大HP，不是立即補血。請查看血條上限；多階護符也只採最高階，低階不會額外再加。

出現獎勵或紀錄異常？

保留訊息、角色名與時間聯絡管理員，不要反覆領取或自行重設尋寶狀態。
